Three Ways to Add Polynomials

Compare how data structures and algorithmic designs impact performance and memory traversal.

Approach 1

Two-Pointer Traversal

Merge two sorted lists simultaneously by walking p and q pointers together, mirroring the merge step of Merge Sort.

Time: O(m + n) | Space: O(1)
Open Two-pointer →
Approach 2

Nested-Loop Traversal

Iterate outer pointer p through P while scanning Q with inner pointer q. Uses visited flags and a final sorting phase.

Time: O(m × n) + sort | Space: O(n)
Open Nested Loop →
Approach 3

Insertion-Based

Initialize R as a copy of P, then incrementally insert and merge each term of Q into R. Includes cursor caching optimisation.

Time: O(m × n) / O(m+n) | Space: O(1)
